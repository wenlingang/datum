Your databases, one quiet window.

所有数据库，一个安静的窗口。

Datum is a lightweight, fast-starting native desktop client for PostgreSQL, MySQL, SQLite and Redis, on macOS, Windows and Linux. Write SQL with completion that knows your schema, browse and edit tables, and keep local, staging and prod apart.

Datum 是一款轻量、启动快的原生桌面数据库客户端，支持 PostgreSQL、MySQL、SQLite 与 Redis，可在 macOS、Windows、Linux 上使用。补全懂你的表结构，浏览、编辑表格，local、staging、prod 分得清清楚楚。

Small, quick, light on memory.

包小、启动快、占用少。

Datum draws its UI with native views, not an embedded browser, and a component updates only the part whose data changed. The result grid creates views only for the visible cells and reuses them as you scroll.

Datum 用各平台原生视图绘制界面，不内嵌浏览器；组件只在依赖的数据变化时更新对应部分，不整页重绘。结果表只为可见区域的单元格创建视图，滚动时复用。

  • ≈ 33 MBMac download (Apple silicon); Windows installer about 22 MBMac 安装包（Apple 芯片）；Windows 安装器约 22 MB
  • ≈ 0.2 sFrom launch to the window appearing从启动到窗口出现
  • ≈ 31 MBMemory while idle空闲时的内存占用
  • ≈ 0.3 sQuery returning 100,000 rows × 10 columns, from running it to rows in the grid查询返回 10 万行 × 10 列，从执行到显示在表格里

Table browsing pages on the server, so a 1,000,000-row table shows its first page in about 0.1 s. Query results stop at 1000 rows by default, adjustable in Settings.

表浏览走服务端分页，100 万行的表首屏约 0.1 秒。查询结果默认最多 1000 行，可在设置里调整。

Measured on an Apple M4 with 24 GB of RAM, macOS 27.2, release build, local SQLite database. Memory is the macOS footprint, as shown in Activity Monitor. See also nsh's performance report.

测试环境：Apple M4、24 GB 内存、macOS 27.2，正式发布的 release 构建，本地 SQLite 库。内存为 macOS 的内存占用（footprint），即「活动监视器」显示的数字。另见 nsh 的性能报告。

Write SQL the way you think.

按你的思路写 SQL。

Completion knows your tables, aliases and columns. Press ⌘↵ to run just the statement under the cursor, format with one key, and keep a history per database.

补全认识你的表、别名和列。按 ⌘↵ 只执行光标所在的那条语句，一键格式化，每个数据库都有自己的查询历史。

Results page on the server, so a big table opens as fast as a small one.

结果在服务端分页，大表和小表打开一样快。

Edit rows, then commit once.

先改，再一次提交。

Change cells and delete rows right in the grid. Nothing touches the database until you press ⌘S, and then everything goes in a single transaction.

直接在表格里改单元格、删行。按下 ⌘S 之前不会动数据库，提交时所有改动放在同一个事务里。

Filter with AND / OR, open any cell in full with JSON formatted, and export to CSV, SQL or Markdown.

支持 AND / OR 筛选，单元格可展开查看完整内容并自动格式化 JSON，可导出 CSV、SQL、Markdown。

Ask in plain words.

用一句话说出你要的数据。

The AI assistant sits next to your tabs and sees the tables of the current connection. Describe what you need, and the SQL it writes shows up as a card you run or open in the editor.

AI 助手就在标签页旁边，能看到当前连接的表结构。说出你想要什么，它写的 SQL 以卡片呈现，由你决定执行还是放进编辑器。

Bring your own provider: OpenAI-compatible, Anthropic or Gemini, with presets for DeepSeek, Qwen, Kimi and more. Nothing runs until you confirm it.

服务商自己配：OpenAI 兼容、Anthropic、Gemini，内置 DeepSeek、通义、Kimi 等预设。不经你确认什么都不会执行。

Hard to shoot yourself in the foot.

不容易误操作。

localstagingprod

Every connection carries its environment's color. DROP, TRUNCATE, or a DELETE without WHERE waits for you to confirm, and read-only connections are enforced by the database itself.

每个连接都带着所属环境的颜色。DROP、TRUNCATE、不带 WHERE 的 DELETE 都要你确认后才执行，只读连接由数据库本身强制保证。

Passwords for staging and prod live in the system keychain: Keychain on macOS, Credential Manager on Windows, Secret Service on Linux.

staging 与 prod 的密码存放在系统钥匙串里：macOS 钥匙串、Windows 凭据管理器、Linux Secret Service。

Imports that roll back cleanly

导入失败整体回滚

Import a .sql file or pasted text in a single transaction. If one statement fails, nothing is applied, and Datum points to the statement that broke.

从 .sql 文件或粘贴的内容导入，全部放在一个事务里。任何一条失败就整体回滚，并指出是第几条出的错。

Redis without the guesswork

Redis 也顺手

Browse keys, view values by type, check TTL and size, and run any command with completion. FLUSHALL asks first.

浏览键，按类型查看值，查看 TTL 与大小，带补全执行任意命令。FLUSHALL 会先问你。

Native, light and dark

原生，浅色深色都好看

Drawn with each platform's own UI through nsh (AppKit, Win32, GTK 4), with a Rust data layer and no WebView. English, Simplified and Traditional Chinese, following your system.

通过 nsh 用各平台自己的界面绘制（AppKit、Win32、GTK 4），数据层是 Rust，没有 WebView。支持英文、简体中文、繁体中文，默认跟随系统。

Everything in Datum

功能一览

Connections

连接管理

Create, edit, test and delete connections, with a live connection-string preview and a database picker that lists what's on the server. SSL off / prefer / require / verify. Colored by environment; staging and prod passwords go to the system keychain. Switch databases from the sidebar, export or drop a database from its menu.

新建、编辑、测试、删除连接，实时预览连接串，数据库可从实例上的库列表里选。SSL 关闭 / 优先 / 必须 / 校验证书。按环境着色，staging 与 prod 的密码存进系统钥匙串。侧栏切库，库的右键菜单可导出、删除。

Tables

表浏览

Server-side paging and sorting, values colored by type, filters with and / or, full cell view with JSON formatting. Stage edits and deletes, then commit them in one transaction. Copy as INSERT, export CSV, SQL or Markdown.

服务端分页与排序，按类型着色，且 / 或组合筛选，单元格全文查看并自动格式化 JSON。暂存编辑与删除后一次事务提交。复制为 INSERT，导出 CSV、SQL、Markdown。

SQL editor

SQL 编辑器

Highlighting, completion that knows your tables, aliases and columns, keywords uppercased as you type. Run the statement under the cursor or the selection, format, Explain, set a row limit, and find past queries in per-database history.

语法高亮，补全认得表、别名和列，关键字自动大写。运行光标所在语句或选区，格式化、Explain、设置行数上限，查询历史按库隔离。

Safety

安全

DROP, TRUNCATE, DELETE or UPDATE without WHERE, and Redis FLUSHALL wait for review. Read-only runs are enforced by the database itself.

DROP、TRUNCATE、不带 WHERE 的 DELETE / UPDATE、Redis 的 FLUSHALL 都要先审查。只读执行由数据库本身强制。

AI assistant

AI 助手

Several providers (OpenAI-compatible, Anthropic, Gemini, with presets), one conversation per connection, your schema and a knowledge document in the prompt. Generated SQL comes as cards you confirm before running.

可配置多个服务商（OpenAI 兼容、Anthropic、Gemini，内置常用预设），按连接分会话，自动带上表结构与知识库文档。生成的 SQL 以卡片展示，确认后才执行。

Interface

界面

English, Simplified and Traditional Chinese; light, dark or system; font and size settings; resizable panes, tabs, and updates inside the app.

英文、简体中文、繁体中文；浅色、深色或跟随系统；字体字号可调；可拖动分栏、多标签页、应用内更新。

ER 图暂未提供。已不再支持 MongoDB，旧版本保存的 Mongo 连接仍留在配置文件里，只是不再显示。

Install

安装

For macOS 14 or later, Windows 10 (1809) or later / Windows 11, and Linux with GTK 4.14 or later and WebKitGTK 6.0 (x86_64).

支持 macOS 14 及以上、Windows 10（1809）及以上 / Windows 11，以及带 GTK 4.14 及以上与 WebKitGTK 6.0 的 Linux（x86_64）。

  1. Download for your system:

    按你的系统下载：

    • Mac: Datum.dmg (Apple silicon; Intel Macs take the x86_64 dmg from Releases). Open it and drag Datum into Applications. Don't run it from inside the dmg.
    • Windows: Datum-setup.exe, then run the installer.
    • Linux: the linux-x86_64.tar.gz from Releases. Unpack it and run Datum/Datum.
    • Mac：Datum.dmg（Apple 芯片；Intel 芯片的 Mac 请到 Releases 下载 x86_64 的 dmg）。打开后把 Datum 拖进「应用程序」。不要直接在 dmg 里运行。
    • Windows：Datum-setup.exe，下载后运行安装器。
    • Linux：到 Releases 下载 linux-x86_64.tar.gz，解压后运行 Datum/Datum。

  2. Datum isn't notarized by Apple, so macOS blocks the first launch. Allow it either way:

    Datum 没有经过苹果公证，第一次打开会被系统拦截。任选一种方式放行：

    • System Settings › Privacy & Security, then Open Anyway at the bottom
    • or before opening the dmg, run xattr -d com.apple.quarantine ~/Downloads/Datum.dmg
    • 打开「系统设置 › 隐私与安全性」，在页面底部点仍要打开
    • 或在打开 dmg 之前执行 xattr -d com.apple.quarantine ~/Downloads/Datum.dmg

    The Windows installer isn't code-signed either. If SmartScreen stops it, click More info, then Run anyway.

    Windows 安装器同样没有代码签名。如果被 SmartScreen 拦下，点更多信息，再点仍要运行。

  3. Add a connection and start querying. Later versions install themselves from Settings › About & Updates. Coming from 0.0.1? That version can't update itself to this one, so download it once by hand.

    新建一个连接就能开始查询。之后的新版本可以在「设置 › 关于与更新」里一键安装。0.0.1 无法自动更新到新版，需要手动下载一次。
