Write SQL the way you think.

按你的思路写 SQL。

Completion knows your tables, aliases and columns. Press ⌘↵ to run just the statement under the cursor, format with one key, and keep a history per database.

补全认识你的表、别名和列。按 ⌘↵ 只执行光标所在的那条语句，一键格式化，每个数据库都有自己的查询历史。

Results page on the server, so a big table opens as fast as a small one.

结果在服务端分页，大表和小表打开一样快。

Edit rows, then commit once.

先改，再一次提交。

Change cells and delete rows right in the grid. Nothing touches the database until you press ⌘S, and then everything goes in a single transaction.

直接在表格里改单元格、删行。按下 ⌘S 之前不会动数据库，提交时所有改动放在同一个事务里。

Filter with AND / OR, open any cell in full with JSON formatted, and export to CSV, SQL or Markdown.

支持 AND / OR 筛选，单元格可展开查看完整内容并自动格式化 JSON，可导出 CSV、SQL、Markdown。

See how everything connects.

一眼看清表之间的关系。

The ER diagram reads real foreign keys and infers the ones you only expressed by naming a column customer_id.

ER 图既读取真实外键，也能从 customer_id 这样的列名推断出逻辑关系。

Drag, zoom, search, and export it as a PNG.

可拖拽、缩放、搜索，并导出为 PNG。

MongoDB, the way you already query it.

用你熟悉的方式查 MongoDB。

Page through a collection with Filter, Sort and Projection, switch between a table and JSON, and edit whole documents without types quietly changing.

用 Filter、Sort、Projection 翻阅集合，在表格和 JSON 之间切换，编辑整篇文档时类型不会悄悄改变。

The query tab speaks a mongosh subset: find, aggregate, updateMany and friends.

查询页支持 mongosh 子集：find、aggregate、updateMany 等。

Hard to shoot yourself in the foot.

不容易误操作。

Install

安装

Universal build for Apple Silicon and Intel Macs.

通用包，Apple Silicon 与 Intel 芯片的 Mac 都能用。

  1. Download Datum.dmg, open it and drag Datum into Applications. Don't run it from inside the dmg.

    下载 Datum.dmg，打开后把 Datum 拖进「应用程序」。不要直接在 dmg 里运行。

  2. Datum isn't notarized by Apple, so macOS blocks the first launch. Allow it either way:

    Datum 没有经过苹果公证，第一次打开会被系统拦截。任选一种方式放行：

    • System Settings › Privacy & Security, then Open Anyway at the bottom
    • or before opening the dmg, run xattr -d com.apple.quarantine ~/Downloads/Datum.dmg
    • 打开「系统设置 › 隐私与安全性」，在页面底部点仍要打开
    • 或在打开 dmg 之前执行 xattr -d com.apple.quarantine ~/Downloads/Datum.dmg

  3. Add a connection and start querying. Later versions install themselves from Settings › About.

    新建一个连接就能开始查询。之后的新版本可以在「设置 › 关于」里一键安装。
