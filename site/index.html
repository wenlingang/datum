Write SQL the way you think.

按你的思路写 SQL。

Completion knows your tables, aliases and columns, writes the ON clause from foreign keys, and offers the real values of a status column after =. Run the statement under the cursor with ⌘↵, or everything with ⌘⇧↵ and get one result tab per statement.

补全认识你的表、别名和列，按外键写好 ON 条件，在 = 后面给出状态列里实际存在的取值。⌘↵ 执行光标所在语句，⌘⇧↵ 执行全部，每条语句一个结果标签。

Errors can go straight to AI for a fix, and Explain plans come back with a plain-language reading.

报错可以直接交给 AI 修，Explain 的执行计划也能让 AI 讲给你听。

Edit rows, then commit once.

先改，再一次提交。

Change cells and delete rows in the grid. Nothing touches the database until ⌘S, and then it all goes in one transaction.

直接在表格里改单元格、删行。按 ⌘S 之前不动数据库，提交时所有改动在同一个事务里。

Filter by typing a sentence: "last 7 days, status failed, amount over 100" becomes AND / OR conditions you can still edit.

筛选可以直接说一句话：「最近 7 天、状态失败、金额大于 100」会变成可以继续修改的且 / 或条件。

Ask, and it looks for itself.

问一句，它自己去查。

AI reads the schema of the current connection and runs read-only queries to answer you. Anything that writes comes back as a SQL card for you to confirm.

AI 会自己查看当前连接的表结构、执行只读查询来回答你。凡是要写入的，都以 SQL 卡片交给你确认。

Bring your own provider: OpenAI-compatible, Anthropic or Gemini, with presets for DeepSeek, Qwen, Kimi and more. Press ⌘J to give the conversation the whole window.

服务商自己配：OpenAI 兼容、Anthropic、Gemini，内置 DeepSeek、通义、Kimi 等预设。按 ⌘J 让对话占满整个窗口。

Hard to shoot yourself in the foot.

不容易误操作。

Every connection carries its environment's color. On prod, even an UPDATE or DELETE with a WHERE shows how many rows it will touch before it runs, and most writes can be undone afterwards.

每个连接都带着环境的颜色。在 prod 上，即使带 WHERE 的 UPDATE、DELETE 也会先告诉你要动多少行，大多数写操作事后还能撤销。

试试看：选一个环境，点运行。

Know what the server is doing.

看清服务器在忙什么。

The diagnostics tab lists sessions, lock waits, long transactions, the slowest statements, unused indexes and dead rows, and lets you cancel or end a session after you confirm.

诊断标签页列出会话、锁等待、长事务、最慢的语句、没用上的索引和死行，确认后可以取消查询或终止会话。

Redis gets its own analysis: memory, the biggest keys, memory by prefix, TTL spread and the slow log, scanned in the background.

Redis 也有专门的分析：内存概况、最大的 key、按前缀统计的内存、TTL 分布和慢日志，在后台渐进扫描。

Everything in Datum

功能一览

Connections连接

Live connection-string preview, a database picker that lists what's on the server, SSL modes, and SSH tunnels with password, key or ssh-agent. Colored by environment; staging and prod passwords go to the system keychain.

实时预览连接串，数据库可从实例上的库里选，支持各种 SSL 模式与 SSH 隧道（密码、私钥或 ssh-agent）。按环境着色，staging 与 prod 的密码存进系统钥匙串。

SQL editorSQL 编辑器

Highlighting, schema-aware completion with JOIN conditions and column values, run one statement or all of them with a result tab each, format, Explain, row limits, per-database history. Tabs and their SQL come back after a restart.

语法高亮，懂表结构的补全，能补 JOIN 条件和列的取值；执行单条或全部，每条一个结果标签；格式化、Explain、行数上限、按库隔离的历史。重启后标签与 SQL 原样恢复。

Tables表浏览

Server-side paging and sorting, values colored by type, AND / OR filters or a plain sentence, full cell view with JSON formatting. Stage edits and commit once. Export CSV, SQL or Markdown.

服务端分页与排序，按类型着色，且 / 或筛选或直接说一句话，单元格全文查看并格式化 JSON。暂存编辑后一次提交。导出 CSV、SQL、Markdown。

Safety安全

Destructive statements wait for review with the number of rows they touch. Single-table UPDATE and DELETE can be undone. Read-only runs are enforced by the database itself.

危险语句先审查，并显示会影响的行数。单表 UPDATE、DELETE 执行后可撤销。只读执行由数据库本身强制。

Diagnostics诊断

PostgreSQL, MySQL and SQLite: sessions, lock chains, long transactions, top SQL, unused indexes, dead rows, integrity checks. Redis: memory, big keys, prefixes, TTL and slow log.

PostgreSQL、MySQL、SQLite：会话、锁等待链、长事务、慢 SQL、未使用的索引、死行、完整性检查。Redis：内存、大 key、前缀、TTL 与慢日志。

AI

Several providers with presets, one conversation per connection, read-only lookups on its own, SQL cards you confirm, fixes for errors and readings of Explain plans.

多个服务商与常用预设，按连接分会话，自己做只读查询，写入以 SQL 卡片确认，能修报错、能解读执行计划。

English, Simplified and Traditional Chinese; light, dark or system; updates inside the app. ER diagrams aren't available yet, and MongoDB is no longer supported.

英文、简体中文、繁体中文；浅色、深色或跟随系统；应用内更新。ER 图暂未提供，已不再支持 MongoDB。

Install

安装

macOS

Datum.dmg

Apple silicon, macOS 14 or later. Drag Datum into Applications. Intel Mac: the x86_64 dmg on Releases.

Apple 芯片，macOS 14 及以上。打开后把 Datum 拖进「应用程序」。Intel 芯片请到 Releases 下载 x86_64 的 dmg。

Windows

Datum-setup.exe

Windows 10 (1809) or later, or Windows 11.

Windows 10（1809）及以上，或 Windows 11。

Linux

linux-x86_64.tar.gz

x86_64 with GTK 4.14+ and WebKitGTK 6.0. Unpack and run Datum/Datum.

x86_64，需要 GTK 4.14+ 与 WebKitGTK 6.0。解压后运行 Datum/Datum。

Datum isn't signed by Apple or Microsoft yet, so the first launch is blocked. On macOS, open System Settings › Privacy & Security and click Open Anyway. On Windows, click More info, then Run anyway. Updates install from Settings › About & Updates afterwards.

Datum 还没有苹果与微软的签名，第一次打开会被系统拦下。macOS：打开「系统设置 › 隐私与安全性」，点仍要打开。Windows：点更多信息，再点仍要运行。之后的新版本在「设置 › 关于与更新」里一键安装。
